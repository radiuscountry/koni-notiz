# Projektregeln: Koni-Notiz

- **Statisch bleiben.** Kein Build-Tool, kein Framework. HTML/CSS/JS direkt, ohne
  Compile-Schritt.
- **Keine Secrets im Code.** Das GitHub-Token wird ausschliesslich vom Nutzer in
  localStorage eingegeben, nie im Repo, im Code oder in einer URL.
- **Sprache: Deutsch**, Schweizer Schreibweise (ss statt ß).
- **ASCII-sichere Dateinamen** (keine Umlaute/Sonderzeichen in Dateipfaden).
- **Am Session-Ende committen und pushen.**

Details zu Ziel, Entscheidungen und Etappenplan: siehe `docs/PROJEKT-BRIEF.md`.
